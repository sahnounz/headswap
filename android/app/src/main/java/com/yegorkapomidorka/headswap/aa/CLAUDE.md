# aa/: Android Auto and the bridge core

See `docs/ARCHITECTURE.md` for the application map and `docs/adr/` for design decisions.

- Read `AaBridge.kt` (~2800 lines) by function rather than in full: `onFrame`/`aaFrame` for video, `onAudio*`,
  `onCarlifeTouch`, `onHuInfo`/`onHuStatistic` for head unit detection, and `attach()` for state reset.
- A new `hu*` head unit flag needs a companion constant, `private set`, **a reset in `attach()`**, initialization in
  `onHuInfo`/`onHuStatistic`, and an `AaBridgeTest` test. Enable it only for the affected head unit (ADR 0006).
- `huVw20082120` means “heartbeat during PAUSE”; it is not limited to VW channel 20082120.
- Server 5277 is single-use: close only through `AapSession.shutdown` (ByeBye → EOF). Do not interrupt a live AA session (ADR 0003).
- `VideoMode` and `CarPreset` are stored in preferences by enum name. Do not rename enum values.
- The choice between passthrough and transcoding is made in four places, listed in the architecture document's Video section.
  If you change one, check the others.
- Package tests are in `android/app/src/test/java/.../aa/`; golden files are in `src/test/resources/aa/`
  (`golden.txt` is generated by `pc-headunit`).
